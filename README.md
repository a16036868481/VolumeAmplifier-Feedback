# Volume Amplifier Plus Feedback

Public bug reports and feature suggestions for **Volume Amplifier Plus** on Windows.
This repository contains feedback documentation only, not the application source code.

[Report a problem](https://github.com/a16036868481/VolumeAmplifier-Feedback/issues/new?template=bug_report.md)
| [Suggest an improvement](https://github.com/a16036868481/VolumeAmplifier-Feedback/issues/new?template=feature_request.md)
| [Microsoft Store](https://apps.microsoft.com/detail/9N7DDKHHPT4S)

## Before Posting

**Issues and their contents are public.** Sign in to GitHub, review the text,
then submit the issue yourself. Opening a draft from the app does not submit it.

- Describe the problem and the steps needed to reproduce it.
- Include the app version, Windows build and whether you use native 1x playback,
  amplification or the equalizer.
- For an installation/security warning, include the error code or detection
  name, but remove personal information and private file paths.
- Do not post full diagnostic logs, audio recordings, account names, email
  addresses, access tokens, license keys, endpoint IDs or other private data.
- Review screenshots carefully. Crop out personal content, notifications and
  account information before attaching them.
- Search existing issues before creating a duplicate.

In app builds that include GitHub feedback, only a short, restricted summary
is prefilled. Raw app logs, Windows event messages and audio-device names are
not included in that public summary. Automatic redaction is not a guarantee
that your own description contains no personal information: review it before
posting. The app does not contain a GitHub write token and cannot submit on
your behalf.

Keep complete diagnostic reports local unless the maintainer asks for them
through a private channel. The app's separate email draft action can be used
for private diagnostics. Do not attach those full reports to public issues.
